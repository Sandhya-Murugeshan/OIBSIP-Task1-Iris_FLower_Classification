# OIBSIP# 🌸 Iris Flower Classification

## 📌 Overview
This project focuses on building a machine learning model to classify iris flowers into different species based on their physical measurements. The model learns patterns from the dataset and predicts the species accurately.

---

## 🎯 Objective
- Classify iris flowers into:
  - Iris-setosa  
  - Iris-versicolor  
  - Iris-virginica  
- Use flower measurements as input features  
- Train a machine learning model for prediction  

---

## 📊 Dataset
The dataset contains the following features:
- Sepal Length (cm)  
- Sepal Width (cm)  
- Petal Length (cm)  
- Petal Width (cm)  
- Species (Target)  

---

## 🧠 Machine Learning Approach
- Data preprocessing (handling labels)  
- Feature selection  
- Train-test split  
- Model training using **K-Nearest Neighbors (KNN)**  
- Model evaluation using accuracy  

---

## ⚙️ Technologies Used
- Python  
- NumPy  
- Pandas  
- Matplotlib  
- Scikit-learn  

---

## 🚀 Project Workflow
1. Load dataset from CSV file  
2. Explore and understand the data  
3. Convert categorical labels into numeric form  
4. Split data into training and testing sets  
5. Train the KNN model  
6. Evaluate model performance  

---

## 📈 Results
- Achieved high accuracy due to well-separated classes in the dataset  
- Model performs well for classification tasks on structured data  

---

## 💡 Key Insights
- The dataset is clean and balanced  
- Petal measurements provide strong separation between classes  
- KNN performs effectively for this type of dataset  

---

## 📌 Conclusion
This project demonstrates the basic workflow of a machine learning classification problem, from data preprocessing to model evaluation.
